# Observabilidade local — PDV-049

O painel “Operações” é exclusivo de ADMIN: GET `/operations/telemetry`, no-store, filtro opcional `traceId`32hex. Mostra contagens/erros/média/p95 de spans nas últimas24h e no máximo100 logs recentes, em snapshot consistente. Contagens não equivalem a vendas; métricas sem amostra ficam vazias. Reconsulta manual, sem collector externo ou deploy.

Checkout HTTP bem sucedido devolve `traceparent`: trace = UUID do pagamento sem hífens; span raiz = primeiros16hex. Replay preserva trace, cria outro span e aponta para raiz. Outbox cria span novo por publicação e envia esse contexto como header AMQP `traceparent`; consumo cria filho com o mesmo trace. O [formato W3C](https://www.w3.org/TR/trace-context/#traceparent-header) orienta a codificação v00. Header incompatível ou sem identidade da operação não é registrado; fallback usa a raiz. Isso instrumenta checkout/mensageria; não declara conformidade completa de um SDK W3C nem cobertura de todos os HTTP/jobs.

API e worker gravam JSON estruturado no logger `pdv.telemetry` e centralizam a mesma projeção em `operation_telemetry`/V19. Campos permitidos: ID, serviço, evento fixo, trace/span/pai, resultado fixo, duração e instante. Sem corpos, motivo administrativo, usuário, cliente, token, stacktrace ou URL arbitrária. Logs gerais do framework continuam separados. Spans são gravados após a transação de negócio, em outra operação; uma falha de centralização gera somente aviso JSON seguro no console e não desfaz venda/ACK. Pode haver lacuna observacional em queda entre o commit e a gravação: telemetria não é ledger financeiro.

Spans de publicação usam a raiz como pai; consumo usa o span recebido. Etapas subsequentes compartilham o trace, sem prometer uma árvore completa de causalidade do banco para cada evento derivado. Operações antigas não recebem spans retroativos. Retenção/volume e exportação para plataforma de produção não estão definidos por esta entrega; o laboratório mantém registros append-only, com índices de tempo/trace. A tabela não contém dumps nem é versionada no Git.
